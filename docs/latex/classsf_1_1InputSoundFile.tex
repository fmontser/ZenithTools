\doxysubsection{Detailed Description}
Provide read access to sound files. 

This class decodes audio samples from a sound file. It is used internally by higher-\/level classes such as \doxylink{classsf_1_1SoundBuffer}{sf\+::\+Sound\+Buffer} and \doxylink{classsf_1_1Music}{sf\+::\+Music}, but can also be useful if you want to process or analyze audio files without playing them, or if you want to implement your own version of \doxylink{classsf_1_1Music}{sf\+::\+Music} with more specific features.

Open a sound file from the disk for reading. 

The supported audio formats are\+: WAV (PCM only), OGG/\+Vorbis, FLAC, MP3. The supported sample sizes for FLAC and WAV are 8, 16, 24 and 32 bit.

Because of minimp3\+\_\+ex limitation, for MP3 files with big (\texorpdfstring{$>$}{>}16kb) APEv2 tag, it may not be properly removed, tag data will be treated as MP3 data and there is a low chance of garbage decoded at the end of file. See also\+: \href{https://github.com/lieff/minimp3}{\texttt{ https\+://github.\+com/lieff/minimp3}}

void sf\+::\+Input\+Sound\+File\+::seek (\begin{DoxyParamCaption}\item[{Uint64}]{sample\+Offset}{}\end{DoxyParamCaption})}



Change the current read position to the given sample offset. 

This function takes a sample offset to provide maximum precision. If you need to jump to a given time, use the other overload.

The sample offset takes the channels into account. If you have a time offset instead, you can easily find the corresponding sample offset with the following formula\+: {\ttfamily time\+In\+Seconds \texorpdfstring{$\ast$}{*} sample\+Rate \texorpdfstring{$\ast$}{*} channel\+Count} If the given offset exceeds to total number of samples, this function jumps to the end of the sound file.
