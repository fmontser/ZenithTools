\doxysubsection{Detailed Description}
Utility string class that automatically handles conversions between types and encodings. 

\doxylink{classsf_1_1String}{sf\+::\+String} is a utility string class defined mainly for convenience. It is a Unicode string (implemented using UTF-\/32), thus it can store any character in the world (European, Chinese, Arabic, Hebrew, etc.).

It automatically handles conversions from/to ANSI and wide strings, so that you can work with standard string classes and still be compatible with functions taking a \doxylink{classsf_1_1String}{sf\+::\+String}.

\DoxyCodeLine{}

\DoxyCodeLine{std::wstring\ s2\ =\ s;\ \textcolor{comment}{//\ automatically\ converted\ to\ wide\ string}}

\DoxyCodeLine{s\ =\ L\textcolor{stringliteral}{"{}hello"{}};\ \ \ \ \ \ \ \ \textcolor{comment}{//\ automatically\ converted\ from\ wide\ string}}

Conversions involving ANSI strings use the default user locale. However it is possible to use a custom locale if necessary\+: 
\begin{DoxyCode}{0}
\DoxyCodeLine{std::locale\ locale;}
\DoxyCodeLine{sf::String\ s;}
\DoxyCodeLine{...}
\DoxyCodeLine{std::string\ s1\ =\ s.\mbox{\hyperlink{classsf_1_1String_ada5d5bba4528aceb0a1e298553e6c30a}{toAnsiString}}(locale);}
\DoxyCodeLine{s\ =\ sf::String(\textcolor{stringliteral}{"{}hello"{}},\ locale);}

\end{DoxyCode}


\doxylink{classsf_1_1String}{sf\+::\+String} defines the most important functions of the standard std\+::string class\+: removing, random access, iterating, appending, comparing, etc. However it is a simple class provided for convenience, and you may have to consider using a more optimized class if your program requires complex string handling. The automatic conversion functions will then take care of converting your string to \doxylink{classsf_1_1String}{sf\+::\+String} whenever SFML requires it.

Please note that SFML also defines a low-\/level, generic interface for Unicode handling, see the \doxylink{classsf_1_1Utf}{sf\+::\+Utf} classes.
